# NetCorp — Game Design Document

The canonical GDD lives as a design artifact in the project thread:
https://ampcode.com/artifacts/netcorp-network-simulation-game-design-document-573ee348-33a0-4b56-b584-975c4609c315

Copy the full text into this file once it stabilizes; until then this page lists the
section map so code review can reference sections:

1. Vision — pitch, design pillars, inspirations map
2. Core Game Loop — build → run → break/respond → grow
3. The Board — physical/logical/simulation views, wiring rules
4. Devices & the Shop — catalog, vendor personalities, used market, no tier treadmill
5. Network Configuration Systems — IP/DHCP/DNS/routing, switching/Wi-Fi, firewall/NAT, services
6. Economy & Progression — Cash/Reputation/Insight, clients & contracts, eras
7. Incidents, Alerts & Cyberattacks — taxonomy, attack table, pager, postmortems, runbooks
8. The Mail System — senders, phishes, action buttons, mail generated by your own network
9. Teamwork — staff traits, delegation, shifts, co-op design
10. Software & Firmware Updates — CVE feed, staged rollouts, EOL
11. Screens & UX — 10 screens, UX principles
12. Technical Direction — pure sim, deterministic commands, parser, data-driven content
13. Balancing & Metrics — bottleneck marking, pacing, failure kindness
14. Scope & Roadmap — MVP "The Garage", v0.5 "The MSP", v1.0, post-1.0
15. Open Questions — realism dial, CLI dialect, art style, business model, multiplayer timing

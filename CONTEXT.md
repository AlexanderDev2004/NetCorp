# CONTEXT.md

The vocabulary the code, data files, and UI copy must use. One name per concept.

## Board & devices

- **Board** — the topology canvas where devices live. Never "canvas", "map", or "scene" in user-facing copy.
- **Device** — anything placeable on the Board (router, switch, desktop, server, AP).
- **Node** — a device as the simulation graph sees it. Internal term; UI copy says Device.
- **Link** — a cable between two device interfaces. Never "edge" or "connection".
- **Interface** — a named port on a device (`eth0`, `wan1`, `wifi0`).
- **Inspector** — the panel showing one device's config, graphs, and logs.

## Simulation

- **Command** — an input that changes world state (place, wire, configure, buy, mail action). All state changes are Commands.
- **Event** — what a Command or tick produced (log lines, alerts, traffic). Events are facts; the UI never invents them.
- **Tick** — one unit of simulated time. The engine advances by ticks; the client requests ticks.
- **Flow** — aggregated traffic between nodes. The default simulation is flow-level; packet-level detail only in Simulation mode.
- **Simulation mode** — the slow-motion packet view for teaching and debugging.

## Business layer

- **Ticket** — a symptom reported by a client or generated by the sim. Tickets never state the cause.
- **Incident** — a sim-driven failure (attack, outage, drift) with severity and a postmortem.
- **Postmortem** — the end-of-incident one-pager: root cause, timeline, one action item.
- **Runbook** — player-written automation for a handled incident class.
- **Contract** — a client relationship: SLA + monthly fee + penalties.
- **Era** — progression stage (Garage → Freelancer → MSP → …).
- **Insight** — research currency. **Reputation** — gates clients. **Cash** — money.

## Mail

- **Inbox** — the mail surface. Senders have personalities (mentor, vendors, clients, attackers).
- **Phish** — a trap mail. Never called "fake mail" or "spam" (spam is merely noise).
- **Spam** — noise mail the filter learns to catch.

## People

- **Staff** — hired co-workers with skill, confidence, communication, quirks.
- **On-call** — whoever owns the pager right now.
